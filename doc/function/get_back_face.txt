Function: get_back_face

--Usage--
> get_back_face(input: card)

Inspects a given [[type:card]]'s links to find one of type "Back Face", and returns the linked card.
Returns nil if no link of type "Back Face", or no card was found.

This function is used by the app to determine which cards must be hidden from the card list
because they are back faces, as well as which cards to group together during print/export.
Its logic can be overwritten in the game's get_back_face_script.

--Parameters--
! Parameter	Type				Description
| @input@	[[type:card]]		The card whose links we'll inspect.
| @set@		[[type:set]]		The set in which to look. This can be omitted since 'set' is a predefined variable.
