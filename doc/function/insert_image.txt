Function: insert_image

--Usage--
> insert_image(base_image: image, inserted_image: image, offset_x: coordinate, offset_y: coordinate, widen: boolean, background_color: color)

Insert an image inside another image.

The inserted_image can be put outside the bounds of the base_image. If the widen parameter is set to true,
the resulting image will be enlarged accordingly. Otherwise, out of bounds portions of the inserted_image will just be discarded. 

--Parameters--
! Parameter				Type				Description
| @base_image@			[[type:image]]		Image that serves as the canvas
| @inserted_image@		[[type:image]]		Image inserted on top of the base image
| @offset_x@			[[type:double]]		Offset of insertion, horizontally, in pixels
| @offset_y@			[[type:double]]		Offset of insertion, vertically, in pixels
| @widen@			[[type:boolean]]		Widen the resulting image to contain the entirety of the inserted image. Optional, defaults to true
| @background_color@	[[type:color]]		Background color. Optional, defaults to transparent
